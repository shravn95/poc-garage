# Tanstack Form + tanstack Router POC

```
- Build a simple login and logout function Using the freeapi.app
- Learn tanstack Routing and Forms

“Technically, we can build everything a library like TanStack Form provides using raw React forms. The main advantage is that the library manages the complexity for us.

For a simple form, I’d probably use React state or native form APIs. But as a form gets more complex—with field-level validation, touched and dirty states, async validation, submission state, dependent fields, and server-side errors—managing all of that manually becomes repetitive and error-prone.

TanStack Form provides a structured and type-safe way to handle those concerns, so I can focus more on the actual application logic instead of maintaining form state and validation infrastructure myself.

So I wouldn't use it just because it's a library; I'd use it when the complexity of the form justifies the abstraction.”
```
